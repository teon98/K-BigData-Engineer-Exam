# K-BigData-Engineer-Exam

### 시험 출제 경향
- 시험시간: 180분
- 합격기준: 100점 만점 60점 이상 (과락 X)

| 유형 | 내용 | 문제 수 |총점수| 참고 |
| --- | --- | --- | --- | --- |
| 1유형 | 데이터 전처리 | 3문제 (각 10점)| 총 30점 | 서브 문제 2문제 or 1문제 | 
| 2유형 | 데이터 분석 | 1문제 | 총 40점| 데이터 분석 → 모델설정 → 평가 → 점수나옴 (해당 점수를 1등 부터 꼴등까지 매겨서 5개 구간 나눠서 상위 부터 40점, 30점, 20점 ... 이렇게 점수 매김) |  
| 3유형 | 통계적 가설 검증 | 2문제 (각 15점) | 총 30점 | 각 문제마다 서브 문제 3문제 등장! | 

👍 1유형에서 20점, 2유형에서 30점~40점, 3유형은 15점(1문제) 정도를 기준으로 하자! (75점 안전 확보!)
